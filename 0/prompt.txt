- Strengthen verification readiness:

  - Keep the exact `VerificationID` row/result binding check.
  - Then count every completed verification whose `CandidateCommit` matches the manifest and require exactly one.
  - Preserve the existing generic `verification ledger binding mismatch` failure and PascalCase ledger JSON compatibility.
  - Add a PostgreSQL integration test with one failed completed attempt and one passed completed attempt for the same candidate; citing the passing row must still fail readiness.

- Separate indeterminate execution from negative evidence:

  - On any verification error, classify `context.Canceled`, `context.DeadlineExceeded`, or an expired caller context as `status:"inconclusive"` and `failed_check:"timeout"`.
  - Preserve context causes when source/toolchain commands fail, and normalize a per-command deadline to `commandCtx.Err()` so process termination is not misclassified.
  - Keep the five-minute overall and 60-second command deadlines.
  - Return CLI exit `3` for `inconclusive`; retain `0` ready, `1` not ready, and `2` invalid manifest.

- Make failed-check classification fail loudly:

  - Change the unwrapped-error fallback from `configuration` to `unknown`.
  - Retain all existing 14 boundary values.
  - Add stable cap values selected by the user: `manifest_count_limit`, `manifest_size_limit`, `prompt_count_limit`, and `prompt_size_limit`.
  - Keep `files` for digest mismatches, symlinks, non-regular files, and other unsafe-file failures.

- Harden directory hashing:

  - Replace raw `unix.Open`/`O_NOFOLLOW` handling with `os.OpenRoot`, `fs.WalkDir(root.FS(), ".")`, and `root.Open(relativePath)`.
  - Continue rejecting discovered symlinks and non-regular files, checking size both before and after open, sorting relative slash paths, and streaming at most 1 MiB plus one byte.
  - Remove the dead `os.NewFile(nil)` handling and redundant root symlink mode condition.
  - Expose typed count/size limit errors so readiness can map manifest and prompt failures to the four stable diagnostics.

- Update `docs/beta-release.md` to document exit `3`, `inconclusive`, `timeout`, `unknown`, the four limit checks, and the shared limits of 64 files and 1 MiB per file.
